# Guide for install WorMe Length determination

WorMe can be executed from the MATLAB Desktop by running the code (license required), or installed/executed as local by installing the MATLAB Runtime 9.11 (licesnse not required).   




|                                | **Running code from MATLAB Desktop** | **Installing WorMe as software** | **Executing WorMe as a local file** |
|--------------------------------|--------------------------------------------|-------------------------------|-------------------------------------|
| **Description**                | Running the code from MATLAB Desktop. | Installing automatically MATLAB Runtime 9.11 and WorMe in the computer. | Installing MATLAB Runtime 9.11 on the computer and executing WorMe as local software.   |
| **Internet Required**          | No                                         | Yes                           | No                                  |
| **MATLAB License Required**    | Yes                                        | No                            | No                                  |
