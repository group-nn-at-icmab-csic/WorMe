# Guide for install WorMe Length determination

WorMe is MATLAB code based software. The software can be executed in three ways:  
- **Executing the code from MATLAB Desktop**: Execute the code from MATLAB Desktop. Doesn't require internet connexion.(fast, but MATLAB License required)  
- **Install WorMe as software**: From installable, MATLAB Runtime 2021b and WorMe Length determination are going to be installed in our computer. Installation require internet connexion. (***No MATLAB license required***)  
- **Executing WorMe as a local file**: Installing MATLAB Runtime 9.11 in our computer, WorMe can be executed without installing it. It can after be installed as software. Doesn't require internet connexion. (***No MATLAB license required***)

All the three ways (from code, installing, or from local) can be installed in Windows, Linux or iOS.
