# Guide for install WorMe Length determination

WorMe is MATLAB code based software. The software can be executed in three ways:  
- **Executing the code from MATLAB Desktop**: Execute the code from MATLAB Desktop. (fast, but MATLAB License required)  
- **Installing the software**: From installable, MATLAB Runtime 2021b and WorMe Length determination are going to be installed in our computer. (No MATLAB license required)  
- **Executing as local file**: Installing Runtime from local file, WorMe can be executed without installing it. It can after be installed as software. No internet connexion needed. (No MATLAB license required)

All the three ways (from code, installing, or from local) can be installed in Windows, Linux or iOS.
